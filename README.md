# thesis-formatter

中南林业科技大学硕士学位论文格式工具。把论文 `.docx` 丢进去，它能做两件事：

- **检查** —— 按学校规范逐条比对，告诉你哪里不合规，并标出每一条是
  「支持自动排版」还是「建议手动修改」。**只读，不改你的文件。**
- **自动排版** —— 按规范改好，另存为新文件。**绝不原地修改。**

正文级的格式（字号、字体、缩进）走样式层，逐段写直接格式未做。

> **非官方个人项目，与学校无关。**
> 规则整理自学校官方模板里的 39 条批注；模板原件与真实论文样本**都不随本仓库分发**
> （前者是学校材料，后者含姓名与未发表内容）。要跑回归测试请自备样本，
> 文件不在时相关测试会自动跳过。

## 装上跑起来

**图形界面**（推荐）：

```bash
python -m pip install -r requirements-gui.txt   # 只有界面需要 PySide6
python app.py
```

拖入 `.docx` → 「开始检查」（只读）或「自动排版并另存…」（可勾"仅预览"）。
结果分四页：重点问题 / 完整清单（按分类折叠 + 搜索 + 按"要不要我动手"筛） /
改动清单 / 文档概况。

**命令行**：

```bash
# 检查一篇论文
python check_docx.py 论文.docx --rules rules/中南林科大_硕士_学术学位_理工类.yaml --report report.md

# 自动排版（先 --dry-run 看会改什么）
python formatter.py 论文.docx --rules rules/xxx.yaml --output 修正后.docx --dry-run
python formatter.py 论文.docx --rules rules/xxx.yaml --output 修正后.docx
```

不想装 Python 的话，用 Releases 里的 exe 或免安装版，解压即用。

## 检查项

页边距 · 页面尺寸 · 页码格式 · 脚注编号 · 缺失章节 · 图表题注编号与中英一致性 ·
字号 · 中文字体 · 西文字体 · 行距 · 段前段后 · 缩进 · 对齐 · 标点全角半角 ·
**标题与正文同段** · **异常字符**（不换行空格/零宽字符/私有区字符/同义字符混用） · 字数

报告分「重点问题」和「完整清单」两段。优先区筛的是**人眼看得见**的问题
（全部错误 + 整体不符规范的类型 + 章节标题类），不是"规则多重要"。

## 自动排版改了什么

四层，改动面从小到大：

1. **文档级**（`w:sectPr`）：页边距、页面尺寸（横向页跳过）、页眉页脚边距、
   页码格式分段（摘要→目录用大写罗马数字，正文起阿拉伯数字重新从 1）。封面与声明页不改。
2. **样式级**（`word/styles.xml`）：把规则写进样式定义（中/西文字体、字号、行距、
   缩进、对齐、大纲级别）。**这是改动量最小的一层**——某样本论文的二级标题的
   `ascii` 字体是宋体（"1.2" 显示成宋体），27 段全错，改 1 处样式全解决。
3. **段落级**（`w:pStyle`）：按分类结果把段落指到对应样式，并清掉会盖住样式的
   直接格式（`spacing`/`ind`/`jc`/`outlineLvl` 与 run 的 `sz`/`szCs`/`rFonts`）。
   加粗、斜体、上下标等**有语义的格式一律不动**。
4. **文本层**（`w:t` 里的字，见 `textfix.py`）：题注图号后插 1 个半角空格；
   异常字符按规则处置（NBSP→半角空格、零宽/私有区字符删除、µ→μ 统一、
   替换字符 U+FFFD 只报不删）；两侧都是中文的半角标点全角化。
   例外：私有区字符 **U+E5E5 换成半角空格而不是删掉**——样本里它顶替空格用
   （六个一级标题只有"第一章"那个位置是它，其余五章都是真空格）。

**跳过的三类**（都写进报告）：

- **含引用域的段落**——实测格式改动会被 Zotero 刷新覆盖，还会触发它的
  "引注已被修改"提示，对用户是纯干扰。见 `zotero_refresh_test.py`。
  注意：文本层是**按节点**避让的，域外的普通文字照改（引用标注旁边的括号不受影响）。
- **目录条目**——由 TOC 域生成，改了会在刷新目录时被覆盖。报告里标成
  「建议手动修改」，别以为是漏了。
- **图片独占一段的段落**——段里没有文字可排，套样式只会给图加上首行缩进；
  而且正文样式的固定行距会把嵌入型图片裁掉。
  段里同时有文字和图片的（标题、题注）**照常排版**，只把行距钉成单倍。

跑完一份 103 页的样本论文（四层全开）：

| | 错误 | 警告 | 提示 |
|---|---|---|---|
| 原稿 | 4 | 73 | 11 |
| 修正后 | 3 | 11 | 7 |

剩下的 3 个错误是内容问题（表4.1/4.2 编号与中英题注不符），不是格式问题。
提示少了 4 条是因为页码分段归一后，说明性条目合并了。

引用域 105 条逐字节不变；除 `document.xml` 与 `styles.xml` 外 69 个 zip 部件哈希全不变。
只开文本层时：29 处题注缺空格、6 个异常字符、13 个半角标点全部处理，
全部 147 条 `w:instrText`（含 105 条 Zotero 引用域）逐字节不变，
run 数 6284、`w:t` 数 5514 均不变，且**只替换 `word/document.xml`**。

两条硬约束写在代码里：**只改 `document.xml` 与 `styles.xml`**（其余部件照抄，
所以"没动别的"可验证）、**拒绝原地修改**（输出路径与输入相同直接抛错）。

## 尚未覆盖

- **只认 `.docx`，不认 `.doc`（Word 97 二进制格式）。** 这不是"还没做"，是能力边界：
  python-docx 读不了旧格式，短期也不会支持。拿 `.doc` 进来会被告知"可能不是有效的
  `.docx`"，先用 WPS / Word 另存为 `.docx` 再跑。
- 分页效果（章末大片空白、图与题注分离）——`.docx` 里没有分页信息，只能从渲染结果判断
- 公式编号与排版
- 封面各字段
- 分类器依赖章节锚点与编号模式；完全不标大纲级别且不用标准编号的文档会退化
- 半角方括号 `[]` 不自动全角化：全角方括号有 ［］ 与 【】 两种写法、语义不同，
  机械替换会改错意思，只降级为"需人工判断"
- 替换字符 U+FFFD 只报不删（删掉等于把"这里丢了字"的线索也删了）
